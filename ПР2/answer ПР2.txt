1. Семантическая верстка использует теги по смыслу (header, nav, main),
   несемантическая — только div/span. Важна для доступности, SEO и читаемости кода.

2. article — для самодостаточного контента, section — для группировки внутри.
   В моей работе article — рецепты, section — «История блюда», «Ингредиенты».

3. header — вводная часть, footer — завершающая. Да, могут использоваться
   многократно: у страницы и внутри каждого article.

4. main — для основного контента. div не несёт смысла: скринридеры
   и поисковики не понимают, что это главное содержимое.

5. nav — семантический блок навигации. Обязателен для меню сайта,
   хлебных крошек, пагинации.

6. datetime задаёт дату в машиночитаемом формате ISO 8601.
   Нужен для поисковиков, календарей и скринридеров.

7. figure + figcaption семантически связывают картинку с подписью.
   Плюсы: доступность, точнее SEO, можно стилизовать блок целиком.

8. aside — для контента, косвенно связанного с основным (боковая панель,
   реклама, популярные статьи). В моей работе — «Популярные кухни».

9. SEO: поисковики точнее понимают структуру и дают расширенные сниппеты.
   Доступность: скринридеры позволяют переходить по ориентирам.

10. Использовал header, nav, main, article, section, aside, footer, figure,
    figcaption, time, details, address, table, form. Они создают смысловую
    карту документа для людей, скринридеров и поисковиков.
