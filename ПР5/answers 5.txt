1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?
Основное свойство - display: grid. Grid - двумерная система (строки и столбцы одновременно), Flexbox - одномерная (либо строка, либо столбец). Grid позволяет явно задавать grid-template-areas, grid-template-columns/rows, управлять перекрытием элементов и создавать сложные макеты без вложенных контейнеров. Flexbox лучше для выравнивания элементов внутри одной оси и распределения свободного пространства.

2. В чем разница между grid-template-columns и grid-auto-columns?
•	grid-template-columns - задаёт явные колонки сетки (те, что описаны в шаблоне).
•	grid-auto-columns - задаёт размер неявных колонок, которые браузер создаёт автоматически для элементов, не поместившихся в явную сетку.
Используют grid-template-columns, когда структура известна заранее; grid-auto-columns - когда количество элементов динамическое (например, при grid-auto-flow: column).

3. Что делают функции repeat(), minmax() и auto-fit?
•	repeat(n, size) - повторяет определение колонок/строк n раз: repeat(4, 1fr).
•	minmax(min, max) - задаёт диапазон размера: minmax(200px, 1fr) - не меньше 200px, но может растягиваться.
•	auto-fit - автоматически подбирает количество колонок под ширину контейнера, растягивая их.
Пример: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); - адаптивная галерея.

5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.
Линии нумеруются с 1 (начало) по N+1 (конец), плюс отрицательные номера с конца (-1 - последняя линия). 

6. Что такое grid-gap (или gap) и чем он лучше margins?
gap задаёт промежутки между grid-элементами (строками и колонками) без внешних отступов по краям. Преимущества перед margin: не нужно убирать отступ у последних элементов, работает симметрично, поддерживает раздельные значения row-gap и column-gap.

7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?
•	justify-items - выравнивание по горизонтали внутри ячейки (start | center | end | stretch).
•	align-items - выравнивание по вертикали внутри ячейки.
Применяются ко всем элементам контейнера; для отдельного элемента - justify-self / align-self.

8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?
•	auto-fill - создаёт максимально возможное количество колонок, даже если они пустые (остаются пустые треки).
•	auto-fit - создаёт столько колонок, сколько нужно, и растягивает существующие на свободное место (пустые треки схлопываются).
auto-fit визуально лучше для галерей, auto-fill - когда важна фиксированная ширина трека.

9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования?
Правила именования: имена - идентификаторы (без пробелов), каждая строка матрицы - строка сетки, количество «слов» в строке = число колонок, области должны быть прямоугольными, точки . обозначают пустые ячейки.

10. Какие преимущества даёт CSS Grid перед другими методами вёрстки?
•	Двумерность - одновременное управление строками и столбцами.
•	Наглядность - grid-template-areas описывает макет «картинкой».
•	Адаптивность - auto-fit, minmax, fr без медиа-запросов.
•	Отсутствие float/clearfix и лишних обёрток.
•	Точное выравнивание через justify/align-items/self.
•	Порядок элементов можно менять без изменения HTML.
•	Вложенные сетки легко комбинируются
