
**1. В чем разница между селектором по классу и по ID с точки зрения специфичности и возможности повторного использования?**
*   **Специфичность:** Селектор по ID имеет более высокую специфичность (1,0,0), чем селектор по классу (0,1,0). Это означает, что стили, заданные через ID, будут иметь приоритет над стилями классов при конфликте.
*   **Повторное использование:** Классы предназначены для многократного использования на множестве элементов. ID должен быть уникальным на всей странице, поэтому его нельзя использовать повторно. Для стилизации лучше использовать классы, а ID — для якорей или JavaScript-хуков.

**2. Как работает каскад в CSS и в каком порядке применяются стили при конфликте правил?**
Каскад - это механизм, определяющий, какое правило CSS будет применено к элементу при конфликте. Браузер использует следующий порядок приоритетов (от низшего к высшему):
2.1.  **Важность (Origin):** Стили браузера по умолчанию < Пользовательские стили < Авторские стили (ваши).
2.2.  **Специфичность (Specificity):** Чем выше специфичность селектора, тем выше приоритет. `!important` имеет наивысший приоритет.
2.3.  **Порядок следования (Order):** Если специфичность равна, применяется правило, которое было объявлено последним в коде.

**3. Рассчитайте специфичность для селекторов:**
*   `ul li.important` -> **0, 1, 2** (0 ID, 1 класс, 2 тега).
*   `#site-title` -> **1, 0, 0** (1 ID, 0 классов, 0 тегов).
*   `.content > .featured-post` -> **0, 2, 0** (0 ID, 2 класса, 0 тегов).

**4. Какие свойства в CSS наследуются по умолчанию, а какие нет? Приведите по 3 примера каждого типа.**
*   **Наследуются:** Свойства, связанные с текстом. Примеры: `color`, `font-family`, `font-size`, `line-height`, `text-align`.
*   **Не наследуются:** Свойства, связанные с блочной моделью и позиционированием. Примеры: `margin`, `padding`, `border`, `width`, `height`, `background-color`.

**5. Как работает селектор > (дочерний селектор) и чем он отличается от селектора потомков (через пробел)?**
*   **`>` (дочерний):** Выбирает только те элементы, которые являются **прямыми** потомками (непосредственно вложенными) указанного родителя.
*   **` ` (потомок):** Выбирает **все** элементы, находящиеся внутри указанного родителя, на любом уровне вложенности (дети, внуки, правнуки и т.д.).

**6. Для чего используются псевдоклассы :hover и :nth-child()? В каких практических задачах они могут пригодиться?**
*   **`:hover`** применяется, когда пользователь наводит курсор на элемент. Используется для интерактивности: подсветка кнопок, ссылок, выпадающих меню.
*   **`:nth-child()`** выбирает элементы на основе их порядкового номера среди братьев/сестер. Используется для создания "зебры" в таблицах (чередование цветов строк) или стилизации каждого третьего элемента в списке.

**7. Что делает правило !important и почему его следует использовать с осторожностью?**
`!important` заставляет браузер игнорировать обычную специфичность и применять это правило в первую очередь. Его следует использовать с осторожностью, так как оно нарушает естественный каскад, делает код трудным для отладки и поддержки. Лучше решать конфликты путем повышения специфичности селекторов.

**8. Как псевдоэлементы ::before и ::after расширяют возможности CSS и какой контент они могут содержать?**
Они позволяют вставлять контент до или после содержимого элемента без изменения HTML-разметки. Они могут содержать текст, изображения (через `url()`), счетчики или просто декоративные элементы (иконки, кавычки), задаваемые через свойство `content`.

**9. В каком порядке браузер применяет CSS-правила при одинаковой специфичности селекторов?**
При одинаковой специфичности применяется правило, которое было объявлено **позже** в исходном коде (или в подключенном файле стилей). Это называется правилом "последнего объявления".

**10. Как инструменты разработчика в браузере помогают анализировать и отлаживать CSS-код?**
Инструменты разработчика (DevTools) позволяют:
*   Просматривать примененные стили для любого элемента.
*   Видеть, какие правила были переопределены (зачеркнуты).
*   Анализировать специфичность селекторов.
*   Изменять CSS-свойства в реальном времени и сразу видеть результат.
*   Отлаживать наследование и блочную модель (Box Model).
